0. 준비물

🔑 카카오 또는 구글 계정

둘 중 아무거나로 로그인하면 돼요.

📱 휴대폰 브라우저

모바일 우선으로 만들었어요. 홈 화면에 추가하면 앱처럼 써요.

🏃 러닝 데이터 — 아래 중 편한 걸로 (하나면 충분)

  • Strava 계정 — 가장 추천. 전체 기록을 한 번에 자동으로, 업로드 없이. ✅
  • 워치/앱 파일 — Garmin·COROS .fit(또는 .zip), Strava .csv
  • 러닝 캡쳐 이미지 — 워치/앱 기록 화면 사진을 올리면 읽어서 기록
  • 직접 입력 — 오늘 10km 50분 평균심박 150 처럼 한 줄로

💡 홈 화면에 추가하면 앱처럼 쓸 수 있어요: 사파리 공유 → 홈 화면에 추가 / 크롬 ⋮ → 홈 화면에 추가.

1. 로그인

  1. 휴대폰 브라우저로 coach.overflow.run 접속
  2. 카카오로 시작 또는 구글로 시작 버튼 탭 → 동의
  3. 처음이면 → 시작하기(데이터 연결) 화면으로, 이미 데이터가 있으면 → 홈으로

🔒 같은 이메일을 다른 제공자(카카오↔구글)로 로그인하면 "이 계정을 연결할까요?"를 물어봐요. 안내대로 고르면 됩니다.

2. 데이터 연결 (온보딩)

데이터가 연결되기 전엔 홈 대신 "데이터를 연결해 주세요" 화면이 떠요. 아래 4가지 중 하나로 연결하면 코칭이 열립니다. 연결하면 곧바로 첫 체력 진단으로 넘어가요.

🟧 방법 A — Strava 연동 (추천)

한 번 연결하면 전체 활동이 자동으로 들어오고, 단건 상세 분석(랩·페이스·심박 차트)도 이 경로에서 열려요.

  1. Connect with Strava (주황 버튼) 탭
  2. Strava 로그인 → Authorize(승인)
  3. 자동으로 OMPB로 돌아오면 끝 — "✅ 연결됨"이 뜨고 홈으로 이동해요
  4. 이후 동기화는 자동이에요. 연결 해제도 설정/온보딩 화면의 연결 해제로 언제든 가능 — 권한이 취소되고 저장된 인증정보가 지워져요. 이미 가져온 기록은 남아요.

📁 방법 B — 워치/앱 파일 업로드

Garmin·COROS .fit(또는 .zip), Strava .csv 파일을 골라 업로드하고 가져오기.

  • 한 파일이 10MB를 넘으면 막혀요 → 그땐 Strava(방법 A)를 쓰세요.
  • 나중에 파일을 더 올려 기록을 계속 쌓을 수 있어요.

📷 방법 C — 러닝 캡쳐 이미지

워치/앱의 기록 화면 캡쳐를 올리면 거리·시간·심박 등을 읽어줘요 → 내용 확인 후 저장. (날짜를 못 읽으면 날짜만 골라주면 됩니다.)

✍️ 방법 D — 직접 입력

오늘 10km 50분 평균심박 150 처럼 한 줄로 입력 → 기록.

3. 둘러보기 — 화면 한눈에

아래 탭으로 이동해요 (화면의 탭바).

🏠 홈 — 오늘 할 일

  • 오늘 대문: 오늘 예정된 훈련(거리·페이스·존·구성)과 한마디. 완료한 날엔 칭찬 + 오늘 훈련 리뷰.
  • 내일 훈련 귀띔, 오늘 날씨 + 미세먼지(도시 설정 시), 체중·연료 카드.
  • 부상 회복 모드 배너(부상 기록 시): 회복 단계·러닝 부하 상한 표시.

💬 코칭 — 무엇이든 물어보세요

"오늘 뭐 뛰어?", "내 체력 어때?", "이번 주 계획 짜줘" 처럼 자유롭게 대화. 주제를 고르면 몇 번의 탭으로 답이 와요. 대화 중 부상이 감지되면 부상으로 기록도 제안해요.

🗓 트레이닝 — 주간 캘린더 + 런 상세

  • 주간 캘린더: 계획 대비 실제 이행을 한 주 단위로. 주를 앞뒤로 넘겨볼 수 있어요.
  • 런 상세: 각 달리기의 런 리뷰(그날 계획·전후 세션·주간 부하 맥락 분석)와, Strava 연결 시 랩 차트 — ① 1km 단위 / ② 구간 랩 원본을 탭으로 전환(거리 표시).
  • 주간 계획 조정: "수요일을 휴식으로", "롱런 줄여줘" 처럼 말하면 조정안(미리보기)을 만들어줘요 → ✅ 적용해서 저장을 눌러야 실제로 반영됩니다. (누르기 전엔 안 바뀌어요!)

🩹 부상 — 아프면 기록

부상을 기록하면 주간 계획이 회복 단계에 맞춰 자동 조정돼요. 체크인으로 회복을 추적합니다.

📊 인사이트 — 데이터가 찾은 "와우 모먼트"

스트라바·가민이 안 보여주는 숨은 추세·자기 기준 기록·패턴을 카드로. 카드를 탭하면 코치가 풀어 설명해줘요.

⚙️ 설정 — 목표·PB·존·내 현황

  • 목표: 대회·거리·목표 기록·레이스 날짜 설정.
  • PB: 기록에서 최고기록 후보를 스캔 → (필요하면 수정 후) 확정 저장.
  • 내 훈련 존: 자동 추정 HRmax 기반 심박 존/페이스 밴드. HRmax 직접 보정도 가능(인사이트·리뷰·계획에 반영).
  • 내 현황: 데이터 충분도·목표·PB·진단·플랜·Strava·이번 달 코치 턴 사용량.

그 밖에

  • 🔬 체력 리포트: 강점·약점·실행 플랜을 담은 진단 리포트(이미지).
  • 🗓 주간 카드: 요일별 세션을 담은 주간 계획 카드(이미지).
  • 👟 신발장: 보유 신발 마일리지 추적 + 오늘 훈련에 맞는 추천.

4. 첫 사용 추천 순서

연결 직후 이 순서로 한 바퀴 돌면 핵심 기능을 다 만나요:

  1. 설정 → 목표 설정 (예: 춘천마라톤 풀 3:10, 레이스 날짜)
  2. 설정 → PB 스캔 → 맞으면 확정 저장
  3. 🔬 체력 리포트 받기 ※ 첫 생성 1~3분
  4. 🗓 주간 카드 받기 ※ 첫 생성 1~3분 · Pro
  5. 홈에서 "오늘 훈련 / 내일 귀띔 / 날씨 / 체중" 확인
  6. 달린 뒤 트레이닝에서 그 런 열어 런 리뷰(+ Strava면 랩 차트) 보기
  7. 그다음부턴 코칭에서 그냥 말로: "오늘 뭐 뛰어?", "내 체력 어때?"

5. 무료 / Pro

Free · ₩0

체력 진단 + 개선 방향성 코칭 — 이번 달 무료 코치 5회.

Pro · ₩9,900/월또는 ₩99,000/년

요일별 주간 상세 계획, 심층 분석, 코치 무제한.

코치 답변(진단·상담·리뷰 등)은 실제 AI가 도는 "코치 턴"이에요. 무료 한도를 넘기면 안내(업그레이드)가 떠요. 베타 동안 한도/Pro 관련은 카톡으로 문의 주세요.

6. 이번 주에 꼭 해봐 주세요 ✅

부담 없이 평소 쓰듯 써보시면 돼요. "한 번씩 건드려 주세요" 목록:

  • 로그인(카카오/구글) — 매끄러웠는지
  • 데이터 연결(Strava / 파일 / 캡쳐 / 직접) — 막히는 지점 있으면 꼭 제보!
  • 설정의 내 현황·목표·PB·훈련 존이 내 상황과 맞는지
  • 체력 리포트 — 이미지가 잘 보이는지, 한글 안 깨지는지(□□□)
  • 주간 카드 / 트레이닝 캘린더 — 계획이 말이 되는지
  • 런 리뷰 — 방금 뛴 런 숫자(페이스·심박·상승)가 정확한지
  • (Strava) 랩 차트 — "1km" / "구간 랩" 탭 전환이 자연스러운지
  • 주간 계획 조정 — 말로 바꾸고 ✅ 적용해서 저장까지 잘 되는지
  • 인사이트 카드가 흥미로운지 / 맞는지
  • 체중 기록(홈 카드) · 부상 기록(부상 탭)
  • 홈 날씨/미세먼지 — 내 도시로 잘 잡히는지
  • 코칭에서 "오늘 뭐 뛰어?" · "내 체력 어때?" — 내 데이터에 맞고 자연스러운지

7. 알아두기 (기대치)

⏱️ 응답 시간

진단·리포트·주간카드·리뷰는 1~3분 걸릴 수 있어요. "준비 중…" 표시가 뜨면 작업 중. 목표 저장·PB 스캔·체중 기록은 즉시.

🗓️ "오늘"은 한국 시간

날짜는 KST 기준이에요. 자정 직후에도 정확합니다.
