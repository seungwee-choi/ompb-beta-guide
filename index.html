OMPB 러닝 코치 — 베타 테스트 가이드 🏃

📅 테스트 기간: 1주 💬 피드백: 카톡방 🤖 플랫폼: 디스코드 DM

OMPB는 디스코드에서 1:1로 대화하는 AI 마라톤 코치예요.
내 러닝 데이터를 연결하면 → 체력 진단 · 주간 훈련 계획 · 오늘의 세션 · 런 피드백을 한국어로 받아볼 수 있어요.
명령어를 외울 필요 없이 평소 말로 물어보면 됩니다.

편하게 써보시고, 떠오르는 건 뭐든 카톡방에 자유롭게 남겨주세요. 🙏

0. 준비물

🎮 디스코드 계정

모바일 앱 / PC / 웹 아무거나 괜찮아요.

✉️ 베타 서버 초대

이미 받으셨어요. 서버에 들어와 계시면 됩니다.

🏃 러닝 데이터 — 둘 중 편한 걸로

  • Strava 계정 — 가장 추천. 전체 기록을 한 번에, 업로드 없이 가져올 수 있어요. ✅
  • 러닝 파일 — COROS/Garmin .fit(또는 .zip), Strava .csv

1. 봇과 대화 시작하기 (1:1 DM)

채팅은 봇과의 개인 DM에서 진행해요. 다른 사람에게 내 기록이 보이지 않아요.

  1. 베타 서버의 멤버 목록에서 OMPB 코치 봇을 찾아 클릭 → 메시지 보내기
    (또는 봇 이름 우클릭 → Message)
  2. DM 창에서 아무 말이나 보내보세요 — 예: 안녕
  3. 봇이 "데이터를 연결해 달라"는 안내로 답하면 정상이에요. 다음 단계로!

💡 서버 공개 채널에서 @OMPB 코치를 멘션하면 간단한 소개와 DM 안내만 와요(개인 기록은 공개되지 않아요). 실제 코칭은 DM(1:1)에서 진행하니, 테스트는 DM에서 해주세요.

2. 데이터 연결 (온보딩)

데이터가 연결되기 전까지는 봇이 어떤 말에도 "먼저 데이터를 연결해 달라"고만 답해요. 아래 둘 중 하나로 연결하면 코칭이 열립니다.

방법 A — Strava 연동 (추천) 🔗

전체 기록을 한 번에 가져오고, 단건 상세 분석(랩·페이스·심박)도 이 경로에서만 열려요.

  1. DM에 strava 라고 입력
  2. 봇이 주는 링크를 열고 → Authorize(승인) 클릭
  3. 승인하면 브라우저가 localhost 페이지로 이동해요 — 빈 화면이나 오류처럼 보여도 정상이에요
  4. 그 페이지 주소창의 전체 URL을 복사해서 → DM에 그대로 붙여넣기
  5. "✅ Strava 연결 완료" 가 뜨면 끝! (인증 코드는 한 번만 쓸 수 있으니, 실패하면 strava로 링크를 다시 받으세요.)

방법 B — 파일 업로드 📎

COROS/Garmin .fit(또는 .zip), Strava .csv 파일을 DM 채팅창에 끌어다 놓기

  • 한 파일이 10MB를 넘으면 업로드가 막혀요 → 그럴 땐 방법 A(Strava)를 쓰세요.
  • 가져온 뒤에는 추가 파일을 올려 계속 기록을 쌓을 수도 있어요.

연결이 끝나면 봇이 백그라운드에서 첫 분석을 준비해요. 잠시 뒤 "✅ 첫 분석이 준비됐어요" 가 뜰 수 있어요.

3. 첫 사용 추천 순서

연결 직후 이 순서대로 한 바퀴 돌려보면 기능을 다 만나요:

  1. 상태 — 내 현황 한눈에 (데이터·Strava·목표·PB·분석·플랜)
  2. pb — 기록에서 추정한 최고기록 후보 확인 → 맞으면 저장 (또는 직접 pb 하프 1:22)
  3. 목표 춘천마라톤 sub-2:49 — 레이스 목표 설정 (대회·목표시간 자유롭게)
  4. week — 이번 주 훈련 카드 받기 (이미지) ※ 첫 생성은 1~3분
  5. report — 체력 분석 리포트 받기 (이미지) ※ 첫 생성은 1~3분
  6. 그다음부턴 그냥 말로: "오늘 뭐 뛰어?", "내 체력 어때?"

4. 명령어 · 말투 치트시트

명령어는 외울 필요 없어요. 막히면 도움말 만 기억하세요.

하고 싶은 것 이렇게 말하면 돼요
🆘 뭐부터 할지 모르겠다도움말 · ?
📋 내 현황 보기상태
🏁 데이터 연결strava · (또는 파일 끌어다 놓기)
🔄 Strava 최신 동기화sync · 동기화
🏅 최고기록 확인/저장pb → 저장 · pb 풀 3:05 · pb 하프 1:22
🎯 레이스 목표 설정목표 JTBC마라톤 sub-3:00 · 목표 (확인)
📅 이번 주 훈련 계획week · 주간
📊 체력 분석 리포트report · 리포트
🏃 오늘 세션 추천오늘 뭐 뛰어?
💬 체력 상담내 체력 어때? · 훈련 계획 짜줘
📝 최근 런 피드백최근 달리기 리뷰 · 오늘 아침런 어땠어?
🔬 단건 상세 분석상세 분석 · 인터벌 분석 (Strava 활동만)
✏️ 주간 카드 수정수요일 wu 4km + 지속주 8km @ 3:50 + cd 2km 로 수정

이 봇은 /슬래시 명령을 쓰지 않아요. 그냥 한국어로 말하면 됩니다. 🙂

5. 이번 주에 꼭 해봐 주세요 ✅

부담 없이, 평소 쓰듯 써보시면 돼요. 아래는 "이건 한 번씩 건드려 주세요" 목록:

  • 데이터 연결 (Strava 또는 파일) — 막히는 지점 있으면 꼭 제보!
  • 상태 · 도움말 이 내 상황을 제대로 보여주는지
  • pb 후보가 실제 내 기록과 맞는지
  • 목표 설정 → week 주간 카드가 말이 되는지
  • report 리포트 — 이미지가 잘 보이는지, 한글 안 깨지는지(□□□)
  • "오늘 뭐 뛰어?" · "내 체력 어때?" — 답변이 내 데이터에 맞고 자연스러운지
  • "최근 달리기 리뷰" — 방금 뛴 런 숫자(페이스·심박)가 정확한지
  • (Strava 연결 시) "상세 분석" — 랩/스플릿 분석이 맞는지

6. 알아두기 (기대치)

⏱️ 응답 시간

코치·리포트·주간카드는 1~3분 걸릴 수 있어요. 입력 중(...) 표시가 뜨면 작업 중. 간단한 명령 상태/pb/목표는 즉시 응답.

🇰🇷 한국어 우선

모든 답변은 한국어로 제공돼요.

🔒 데이터 격리

개인 데이터는 디스코드 계정별로 분리·격리돼요. 다른 테스터에게 내 기록이 보이지 않아요.

🧪 베타 특성

운영자의 PC에서 돌아가는 동안만 봇이 온라인이에요. 가끔 멈추거나 이상한 답을 할 수 있어요 — 그게 바로 우리가 찾는 거예요!

  • 🗑️ 데이터 삭제를 원하면 언제든 카톡으로 말씀해 주세요 (Strava 연결 해제 포함).
  • ⚠️ 빨간 ⚠️ ... 오류 메시지가 보이면 그 화면을 캡처해 주세요. 가장 도움돼요.

7. 피드백 보내는 법 💬

전부 카톡방에 자유롭게! 형식은 안 따져요. 다만 이런 게 있으면 추적이 쉬워요:

  • 무엇을 했고 (보낸 메시지) → 무슨 일이 일어났나 (봇 답변/에러)
  • 가능하면 스크린샷 한 장
  • 느낀 점: 좋았던 점 / 헷갈린 점 / "이게 됐으면" 싶은 기능
